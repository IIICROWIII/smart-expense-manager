# Team contribution records

Each member authors one Markdown file named:

`STUDENT_NAME_STUDENT_ID_GITHUB_USERNAME.md`

Replace spaces in the student's name with underscores. Example from the assignment: `HASAN_KAYA_230123123_hasankayyya.md`.

Include your role, implemented features, changed files, decisions you can explain, verification you performed, and relevant commit links. Record actual work and use your own GitHub identity for commits. This guide is not a member contribution record.
